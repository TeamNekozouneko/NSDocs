# 有料ランク特典
Nekozouneko Serverでは、[クリエイティア](https://frontier.creatia.cc/fanclubs/2290)で有料ランクを加入していただいた方に、ロビーサーバーで使える特典を用意しています。

## 連係方法
特典を利用するには、クリエイティアとDiscordとの連係とDiscordとMinecraft サーバーとの連係をしていただく必要があります。

### クリエイティアとDiscordとの連係
[クリエイティアヘルプセンター](https://help.creatia.cc/archives/1059)の記事を参考の上、Discordアカウントと支援をしていただいたクリエイティアのアカウントを連係してください。

連係をしましたら、[支援中のファンクラブ](https://official.creatia.cc/me/joining)よりDiscord参加リンクをクリックして参加処理を実行してください。

### DiscordとMinecraftとの連係
[参加方法](/how-to-join)に従って、Nekozouneko Serverに接続してください。

ロビーサーバーで`/discord link`を実行してください。その後、連係用の4桁のコードが表示されるので、「ロビー鯖（Nekozouneko Server - ロビー #3446）」にコードをダイレクトメッセージで送信してください。

成功すれば、「あなたは&lt;MCID>と連係しました！」と表示されます。

## 使用方法
有料ランク特典には次のものがあります。
* 浮遊
  * クリエイティブ状態のように自由に浮遊することができます。
* 3段ジャンプ
  * 通常ジャンプと追加の2段ジャンプをすることができます。空中にいる状態で2回連続でジャンプしようとすると空中でジャンプします。
* スキンの大きさの変更
  * スキンの大きさを25、50、75、通常（100%）、125%の5段階で変更できます。
* 時間の変更
  * 自分からのみ見える時間を変更できます。
* 天候の変更
  * 自分からのみ見える天候を変更できます。
* ポーションの効果
  * イルカの好意（泳ぐ速度上昇）、移動速度上昇、ジャンプ力上昇、移動速度低下、暗視、落下速度低下をLv.1と2の効果を自由に適応できます。
* 他のプレイヤーから姿を隠す
  * 他のプレイヤーから姿を隠します。ただしモデレーター等からは見ることができます。

ロビーサーバーに接続した際、ホットバーの右端にある「**寄付メニュー**」を右クリック（使用）するか、`/dmenu`で有料ランクメニューを開くことができます。メニュー内をそれぞれクリックしたりすることで特典機能を有効化できます。

有効な機能はアイテムがエンチャント状態のようになっています。また一部の機能はクリックすると別の天気に変更されたり、別のメニューが開かれるものもあります。
* 天候の変更
  * 雨 -> 晴 -> リセット（サーバーの天候に依存）に変更されます。
* スキンの大きさの変更、時間の変更、ポーション効果を設定
  * それぞれの専用のメニューがあります。

### 専用メニュー
#### スキンの大きさの変更
左側の羊毛は、- 75、- 50、- 25%の順に並んでいます。それぞれクリックし適応できます。

リセット（バリアブロック）を押すとスキンの大きさがデフォルトに戻ります。

右側の羊毛は、+ 25%があり、クリックし適応できます。

#### 時間を設定
早朝、昼間、夕方、夜中の順に並んでいて、それぞれマイクラ基準で、0、6000、13000、18000に変更されます。右端のバリアブロックはリセットし、サーバーで設定されている時間に戻ります。

#### ポーション効果を設定
上にある牛乳入りバケツをクリックすると、設定中のポーション効果がリセットされます。（この機能以外で設定された効果はリセットされません。）

下にあるポーションをクリックすると、それぞれ説明欄にある効果が適応され、クリックするたびにLv.1 -> Lv.2 -> リセットのように変更されます。

### コマンド
| コマンド | 説明 |
| ------- | --- |
| `/dfly` | 実行するたびに浮遊機能の有効無効を切り替えます。 |
| `/dhide` | 他のプレイヤーから隠れる機能を有効に切り替えます。 |
| `/dmenu` | 有料ランクメニューを開きます。 |
| `/dpotion` | ポーション効果のメニューを開きます。 |
| `/dreveal` | 他のプレイヤーから隠れる機能を無効に切り替えます。 |
| `/dscale` | スキンの大きさを変更するメニューを開きます。 |
| `/dtime [time]` | 時間を設定するメニューを開きます。time引数が指定されている場合、その時間に設定します。 |
