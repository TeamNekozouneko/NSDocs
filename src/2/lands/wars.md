# 戦争する
このサーバーには、Landsプラグインの戦争機能があります。

## 戦争の手順
### `①相手を敵対状態にする`
`/lands`から「関係性」→「敵」→「追加」を押して、チャットに相手の集団名をチャットに入力します。
### `②宣戦布告を行う`
`/war declare <集団名>`で相手に宣戦布告を行います。
::: info 攻め側/守り側
今後、宣戦布告をした方を「攻め側」、宣戦布告をされた方を「守り側」と記載します。
:::
#### トリビュートの設定
コマンドを実行して、トリビュートを指定します。
::: tip トリビュートとは
トリビュートとは、戦争中に相手が途中で降伏をした場合に支払わなければならない攻め側の要求金額です。（守り側の銀行残高の`75%`を超えるトリビュートを設定することはできません。）
:::
![](/images/lands/war_tribute.png)
#### 宣戦布告を送信する
トリビュートを設定したら、画面右下の「宣戦布告を送信する」を押して相手に送信します。
### `③相手が宣戦布告を承諾する`
秩序維持のため、相手が宣戦布告に承諾しないと戦争が始まりません。承諾されると、`10分後`に戦争が始まります。
### `④戦争中`
戦争は最大で`1時間`続きます。しかし、最初に**勝利ポイント数**を獲得した陣営があれば、その時点でその陣営が勝利します。
::: tip 勝利ポイント数とは？
勝利ポイント数は、攻め側と守り側で所属人数が少ない方の所属人数に`5`を掛けた数です。ただし、勝利ポイント数が100を下回る場合は、100が勝利ポイント数になります。

計算式: `max(100, 5×攻め側と守り側で所属人数が少ない方の所属人数)`
:::
#### 戦争方式
戦争中、敵陣地の中はPVPが互いに有効になります。敵陣営に所属するプレイヤーを倒すことで**1ポイント**獲得します。または、次のレシピで作成した占領旗を、敵陣地のどこかのチャンクに設置して占領すると**5ポイント**を獲得します。しかし、攻め側が設置した占領旗が守り側に破壊されると、守り側が**3ポイント**を獲得します。
::: tip 占領旗のクールダウン
占領旗は、一度設置すると次設置ができるまで5分間のクールダウンがあります。
:::
![](/images/lands/war_recipe.png)
#### 降伏
`/war menu`の「トリビュート」から降伏することができます。
### `⑤戦争の終了と勝敗`
戦争を終了して勝敗を決めるには、次の3つのパターンがあります。
#### 降伏（サレンダー）
攻め側または守り側が降伏（サレンダー）した場合、戦争が終了します。
`/war menu`の「トリビュート」から降伏することができ、降伏された側が勝利します。
#### 勝利ポイント数を獲得
攻め側または守り側のどちらかが勝利ポイント数を獲得した場合、戦争が終了します。
勝利ポイント数を獲得した側が勝利します。
#### タイムアウト
戦争開始から1時間が経過した場合、戦争がその時点で終了します。
終了時点で獲得したポイントが多い方が勝利します。
::: tip 獲得したポイントが同じだったら
終了時点で攻め側も守り側も獲得したポイントが同じだった場合、戦争は引き分けとなります。
この場合、両者とも報酬は得られません。
:::
### `⑥報酬`
原則として、戦争に敗北した場合、勝利した側に銀行残高の`75%`が自動的に支払われます。（敗北した側の銀行残高から支払った金額が差し引かれます。）

ただし、戦争の終了方法が`降伏（サレンダー）`の場合は、次の2つのパターンのどちらかで支払いが行われます。
#### 攻め側が降伏した場合
固定で`300G`が守り側に支払われます。
#### 守り側が降伏した場合
宣戦布告時に提示したトリビュート分が攻め側に支払われます。
