## 統合について
次の理由により、サバイバルサーバーをライフサーバーへ統合します。
* （運営面）  
サバイバルサーバーは、運営のしやすい軽量設計を前提に作られておらず、現状ライフサーバーよりもサーバースペックを要する上に、20人ほど同時に参加するだけでTPS※が10を下回ることがあります。しかし、ライフサーバーは70人ほどが同時に参加してもTPSは20近くを維持しています。  
サバイバルサーバーにおいては、要する維持費に対する効果が低く、より多くの皆様にご利用いただけるような仕組みを作るため、統合をすることといたしました。
::: tip ※TPS
サーバー自体がどのくらいの頻度で処理できているか、20を基準として値が下がるほど処理に時間がかかります。（Pingとは違います）
:::
* （方針面）  
自由と軽量を求めているライフサーバーですが、それを突き詰めるとライフサーバーはサバイバルサーバーの要素・仕様を内包しているようなものです。今後、2つのサーバーを1つにまとめ、サバイバルサーバーの要素をライフサーバーで遊べるようにしていきたいという方針の元、統合をすることといたしました。

## 統合の詳細
* （所有物について）  
「建築」「アイテム」「エンティティ」は、ライフサーバー側に移行可能です。移行方法は後ほどご説明します。
::: tip ちなみに
* 建築は、あなたの家や素敵なマップアートなどです。  
（ただし、家の中にあるエンティティは同時に移行されます。）
* アイテムは、インベントリーやエンダーチェストなどにある物です。
* エンティティは、防具立てや額縁、没入感のある絵画などです。
:::
* （統合後について）  
完全な統合が完了次第、サバイバルサーバーは閉鎖されます。統合後はライフサーバーをご利用ください。

### 移行ステップ
1. （サバイバルサーバーに入る）  
移行したいものを考えておいてください。 
2. （座標や特徴をメモする）  
この後、申請を出すために移行したいものの座標や特徴をメモしておいてください。
3. （ライフサーバーに入る）  
移行したい場所を探してください。
4. （座標や特徴をメモする）  
どの場所に移行したいか座標や特徴をメモしておいてください。  
5. （申請フォームを記入する）  
メモしてある座標や特徴をもとに、フォームの記入を進めていってください。一つのフォームだけで書ききれないときは何回かに分けて送って大丈夫です。
6. （フォームを送信する）  
「送信」ボタンを押すことで申請は完了です。
::: warning 注意
今回、申請数が非常に多くなることから次のような場合には、**簡単に却下されてしまいます**。  
※**これらの例はすべてダメな例です**。絶対にやっちゃダメです。
* **移行したいものが特定できない**  
（例：「〇〇さんにもらったダイヤモンド全部」「空のどこかにある浮島」）
* **自分のものではないものを移行しようとした**（一部例外あり）  
（例：「〇〇さんが作ったお家」「〇〇さんの持ってるチェスト全部」）
* **移行先の指定があいまいでどこに移行すればいいかわからない**  
（例：「私がいるところ辺りに」「私の作った教会の前」）
* **記載されている内容が解読不能**  
（例：「新しい拠点を作り直すことに決めたのですが、地下深くの深層岩をとってきて遠くの村に置いた松明が目印なんですけど、移行してほしい内容は3つあって、ちなみに僕高校生なんですがその3つの中でも4つになっていて私が見ている手前に黒っぽく見えないけど建物があって...」）
* **もはや書かない**  
（例：「すみませんぼくの建築を移行してください」）
:::

## よくありそうな質問
::: info 申請が却下されました、再申請は可能ですか？
はい、却下されても後から何度も申請することは可能です。ただし、却下された理由を見て内容を改善しないと再度却下され続けてしまうことがあります。
:::

::: info サブアカウントで申請することは可能ですか？
はい、サブアカウントで申請することは可能です。ただし、記入されたMCIDと建築の所有者が異なる場合は却下される可能性がありますので、MCIDに`(サブアカウント)`などの表記をお願いします。
:::

::: info 代理での申請は可能ですか？
はい、代理での申請も可能です。ただし、記入されたMCIDと建築の所有者が異なる場合は却下される可能性がありますので、MCIDに`(代理)`などの表記をお願いします。

また、代理での申請を行う場合は、その建築の所有者に許可を得ている必要があります。
:::

::: info 移行したい同じ建築の中で複数の所有者がいます。
例えば、同じ一体になっている家の中で部屋ごとに所有者が異なる場合は、関係者全員の許可を得ればその建築ごと移行することができます。

ただし、記入されたMCIDと範囲内の建築の所有者が異なる場合は却下される可能性がありますので、MCIDに`(全員同意済み)`などの表記をお願いします。
:::

## わからないことがあったら
ご不明な点やどうしても申請が難しい場合は、[Discordのサポートセンター](https://docs.nekozouneko.net/discord)、`admin@nekozouneko.com`までお問い合わせください。

ただし、個別対応は少々時間をいただくことがあります。また、軽微な内容であれば原則として申請フォームを使用してください。
